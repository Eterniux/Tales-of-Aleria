# Tales of Aleria

A C++ dungeon-based game featuring procedural generation, developed as a university project without external libraries or APIs.

## Features
- Procedurally generated dungeon layouts
- Core gameplay systems implemented from scratch
- Custom handling of movement, interactions, and game logic
- Memory and system-level control using C++

## Technical Overview
The project focuses on building core game systems manually, including:

- **Procedural Generation System**
  - Dynamically generates dungeon layouts at runtime
  - Ensures variability in each playthrough

- **Game Loop**
  - Handles input, updates game state, and renders output

- **Entity / Player System**
  - Manages player state, movement, and interactions

## Technologies
- C++
- No external libraries (standard library only)

## How to Run
1. Clone the repository
2. Compile using a C++ compiler (e.g., g++)
3. Run the executable

## Notes
This project was developed as part of a university requirement to build a game system without relying on external engines or frameworks.
